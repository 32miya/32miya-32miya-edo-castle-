# 江戸城さんぽ

徳川将軍家の居城・江戸城（東京都千代田区・特別史跡）を、スマホで歩いて巡れる3D散策アプリ。お城さんぽシリーズの第11城です。

- **江戸時代（寛永〜明暦・焼失前）**: 寛永15年（1638）に3代家光が建てた寛永度天守（外観5重・内部5階地下1階、金の鯱・銅瓦・黒い壁）を穴蔵から最上階まで。本丸御殿の表（遠侍・大広間・松之大廊下・白書院・黒書院）→ 中奥（御座之間・御休息之間）→ 御鈴廊下の御錠口 → 大奥（御鈴番所・御小座敷・御台所の御座所・御仏間・御化粧之間・長局向・広敷向と七つ口）を中から歩けます。大手門・百人番所・中之門・中雀門・富士見櫓・二の丸・西の丸、大名屋敷と日本橋の町も。
- **現代**: 皇居東御苑（天守台に登れる・富士見多聞の中・百人番所・二の丸庭園・大芝生）、皇居外苑と二重橋、大手町・丸の内と東京駅
- **明暦の大火（明暦3年・1657）**: 本郷からの出火 → 天守の炎上 → 大名屋敷の焼失 → 焼け跡と江戸のつくり直し を自動案内でたどる

公開: https://32miya.github.io/32miya-32miya-edo-castle-/

距離は実際より縮め、建物の配置と寸法は簡略化しています。天守・本丸御殿・大奥の内部の間取りと調度は、絵図・屏風・建地割図などの記録に、言い伝えと想像を補った再現です。共通素材は https://32miya.github.io/oshiro/common/ を使います。
